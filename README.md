# СтройСмета v2

Telegram-бот для расчёта строительных работ и материалов.

## Что есть
- несколько объектов на одного пользователя;
- комнаты и автоматический расчёт пола/потолка/стен;
- двери и окна с вычетом из площади стен;
- собственный прайс работ;
- собственный каталог материалов: упаковка, цена, расход, запас;
- добавление работ и материалов в объект;
- редактирование данных объекта;
- удаление комнат, цен, материалов и объектов;
- итоговая смета;
- Excel и Word;
- быстрый расчёт;
- /cancel для отмены любого ввода;
- изоляция данных пользователей.

## Запуск
1. Создайте `.env` рядом с `main.py`.
2. Добавьте `BOT_TOKEN=...`.
3. Установите зависимости: `pip install -r requirements.txt`
4. Запустите: `python main.py`
